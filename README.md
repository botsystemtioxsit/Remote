# Phonecast

Трансляция экрана Android-телефона на ноутбук с Linux **по USB-кабелю** с полным управлением:
мышь работает как палец, клавиатура печатает текст, а для игр можно **назначить клавиши и мышь
на кнопки на экране**: джойстик на WASD, обзор мышью, стрельба на ЛКМ и так далее.

Приложение на телефон ставить не нужно. Захват экрана, звука и ввод касаний выполняет
[scrcpy-server](https://github.com/Genymobile/scrcpy): это небольшая Java-программа, которая
временно запускается через ADB и исчезает после отключения. Всё, что работает на ноутбуке
(окно, декодирование видео, раскладки, редактор), реализовано здесь, на Python.

- Обычное приложение: значок в меню, окно ожидания телефона, автопереподключение
- **ПК-режим**: телефон видит настоящую клавиатуру и мышь, и игры вроде Minecraft
  переключаются на управление как на компьютере
- Видео H.264 с аппаратного кодировщика телефона, до 60 FPS, низкая задержка
- Звук с телефона (Android 11+)
- Мультитач: джойстик, прицел и кнопки можно зажимать одновременно
- Редактор раскладки прямо в окне, профили для каждой игры, автопереключение по приложению
- Клавиши определяются по физическому положению, поэтому WASD работает и при русской раскладке

## 1. Подготовка телефона (один раз)

1. **Настройки → О телефоне** → 7 раз нажмите «Номер сборки», чтобы включить режим разработчика.
2. **Настройки → Для разработчиков** → включите **Отладка по USB**.
3. Только для **Xiaomi / Redmi / POCO**: там же включите **«Отладка по USB (настройки безопасности)»**.
   Без этого картинка будет, а касания работать не будут.
4. Подключите телефон кабелем. На телефоне появится запрос «Разрешить отладку по USB?».
   Отметьте «Всегда разрешать» и нажмите «Разрешить».

Кабель должен передавать данные, а не только заряжать.

## 2. Установка на ноутбук

```bash
# Ubuntu / Debian / Mint
sudo apt install adb python3 python3-venv pulseaudio-utils xclip
# Fedora:  sudo dnf install android-tools python3 pulseaudio-utils xclip
# Arch:    sudo pacman -S android-tools python libpulse xclip

git clone <этот репозиторий> && cd Remote
./install.sh
```

`install.sh` создаёт виртуальное окружение `.venv`, ставит зависимости (PyAV, pygame, numpy),
скачивает `scrcpy-server` с проверкой контрольной суммы и добавляет **Phonecast в меню приложений**.

**Chromebook:** чтобы Linux видел телефон, при подключении кабеля нажмите уведомление
«Подключить к Linux» (или **Настройки → О ChromeOS → Разработчики → Среда разработки Linux →
Управление USB-устройствами** и включите телефон).

## 3. Запуск

Откройте **Phonecast** из меню приложений. На Chromebook он лежит в папке «Приложения Linux»,
его можно закрепить на панели.

Окно ждёт телефон и подсказывает, что сделать, если его не видно. Когда телефон найден,
трансляция начинается сама. Если выдернуть кабель, программа вернётся к ожиданию и
переподключится, когда кабель вставят обратно. Если у пользователя нет доступа к USB-устройству
(так бывает на Chromebook), программа сама перезапускает `adb` с нужными правами.

Настройки хранятся в `~/.config/phonecast/settings.json`:

```json
{
  "version": 2,
  "max_size": 1280,
  "bit_rate": "6M",
  "max_fps": 60,
  "audio": true,
  "fullscreen": false,
  "screen_off": false,
  "mode": "control",
  "pc_mode_apps": ["com.mojang.minecraftpe"]
}
```

`max_size` — размер видео по большей стороне (0 — как на телефоне), `screen_off` — гасить экран
телефона во время трансляции, `pc_mode_apps` — приложения, в которых ПК-режим включается сам.

Запуск из терминала (`./run.sh`) тоже работает, а параметры командной строки перекрывают
настройки (полный список в `./run.sh --help`):

| Параметр | Что делает |
|---|---|
| `-f` | сразу в полноэкранном режиме |
| `-m 1920` | разрешение видео (по большей стороне); `-m 0` — как на телефоне |
| `-b 16M` | битрейт видео: выше — чётче, но больше нагрузка |
| `--max-fps 90` | ограничение FPS (если телефон умеет больше 60) |
| `--screen-off` | выключить экран телефона (трансляция продолжается, батарея экономится) |
| `--no-audio` | без звука |
| `-p "Шутер (пример)"` | запустить с этим профилем раскладки |
| `-s SERIAL` | выбрать телефон, если подключено несколько |

### Два режима

- **Только трансляция** — картинка и звук телефона, больше ничего: мышь и клавиатура на
  телефон не передаются, игровые раскладки и ПК-режим не включаются. Удобно, чтобы просто
  смотреть видео или показывать экран.
- **Трансляция + управление** — всё, что описано ниже: мышь как палец, клавиатура,
  раскладки для игр, ПК-режим.

Режим выбирается кнопками в окне ожидания телефона и запоминается. Во время трансляции
подведите мышь к верхнему краю окна: там кнопка переключения режима (без переподключения).
В режиме трансляции работают только **F1** (справка) и **F11** (полный экран).

## 4. Управление

| Клавиша | Действие |
|---|---|
| **ЛКМ** | касание / свайп |
| **ПКМ** | «Назад» (если экран выключен, включает его) |
| **СКМ** (колесо) | «Домой» |
| Колесо | прокрутка |
| Клавиатура | ввод текста, включая кириллицу; Enter, Backspace и стрелки работают |
| **Ctrl+V** | вставить на телефон текст из буфера обмена ноутбука |
| **F1** | справка |
| **F2** | вкл/выкл раскладку (игровой режим) |
| **F3** | редактор раскладки |
| **F4** | показать/скрыть подсказки кнопок поверх игры |
| **F5** | следующий профиль |
| **F6** | недавние приложения |
| **F7** | шторка уведомлений |
| **F8 / F9** | громкость − / + |
| **F10** | выключить/включить экран телефона |
| **F11** | полный экран |
| **F12** | ПК-режим: телефон видит клавиатуру и мышь (см. ниже) |

## 5. ПК-режим: настоящая клавиатура и мышь (Minecraft и др.)

Нажмите **F12**. Программа создаст на телефоне виртуальную USB-клавиатуру и мышь, и Android
будет считать, что к нему подключены настоящие. Игры, которые умеют работать с клавиатурой и
мышью, переключаются на ПК-управление:

- **Minecraft** — WASD, пробел, Shift, мышь крутит камеру, ЛКМ/ПКМ ломать/ставить, колесо — слоты,
  E — инвентарь, Esc — пауза. Раскладку кнопок настраивать не нужно.
- Курсор мыши появляется на экране телефона. Мышь компьютера захватывается окном.
- Все клавиши, включая F1–F10, уходят в телефон. Программа оставляет себе только **F11**
  (полный экран) и **F12** (выйти из ПК-режима). Если переключиться в другое окно (Alt+Tab),
  мышь освобождается.

Для Minecraft (`com.mojang.minecraftpe`) ПК-режим **включается сам**, когда игра открыта, и
выключается, когда вы из неё выходите. Другие игры можно добавить в `pc_mode_apps` в настройках.

Если игра не понимает клавиатуру и мышь, используйте раскладку из следующего раздела: она
нажимает кнопки на экране касаниями и работает в любой игре.

Виртуальная клавиатура использует английскую раскладку. Русский текст в ПК-режиме не
напечатается; для набора текста выйдите из ПК-режима (F12).

## 6. Раскладка для игр с сенсорным управлением

### Готовые профили: Standoff 2 и Brawl Stars

Оба профиля включаются сами, когда игра открыта на телефоне.

**Standoff 2** — WASD ходьба, мышь сразу крутит камеру, **ЛКМ** огонь, **Пробел** прыжок,
**Ctrl** или **C** присесть, **R** перезарядка (нажатие на счётчик патронов), **Q** смена оружия
(панель оружия справа), **Tab** счёт, **Esc** пауза, **Alt** — меню игры (мышь освобождается).
Кнопки, которые появляются только иногда (прицел снайперки, граната, установка бомбы),
добавьте сами в «Настройке управления», когда они будут на экране.

**Brawl Stars** — WASD ходьба. **ЛКМ** — атака с прицелом: зажмите, наведите курсор, куда
стрелять (относительно своего бойца в центре экрана), отпустите. Чем дальше курсор, тем
дальше бросок. Клик без движения мыши по бойцу — автоприцел. **ПКМ** — суперспособность так же,
**Пробел** — быстрая атака (автоприцел), **E** — гаджет, **Q** — гиперзаряд. **Alt** — меню
игры: ЛКМ снова нажимает кнопки, ещё раз **Alt** — обратно в бой.

**Кнопки в профилях расставлены по стандартному расположению интерфейса игр и примерно.**
Если у вас другой телефон или вы меняли расположение кнопок в игре, откройте игру, нажмите
**F3** и перетащите круги на кнопки игры (см. «Настройка управления» ниже).

### Бой и меню: Alt

Когда раскладка игры включена (режим «бой»), клавиши и мышь нажимают кнопки игры. Чтобы
нажимать меню, магазин и настройки игры, нажмите и отпустите **левый Alt**: включится режим
«меню», где мышь снова работает как палец, а клавиатура — как обычно. Ещё раз **Alt** —
обратно в бой. Текущий режим написан вверху окна.

### Настройка управления

Нажмите **F3** или кнопку **«⚙ Настроить управление»**: она появляется, если подвести мышь
к верхнему краю окна. Справа от экрана телефона откроется панель, как в BlueStacks:

- **перетащите** из панели на кнопку игры нужный тип: «Кнопка», «Атака с прицелом»,
  «Джойстик WASD», «Обзор мышью (FPS)», «Свайп». Для кнопки, атаки и свайпа сразу нажмите
  клавишу или кнопку мыши, которой они будут управляться;
- **клик по подписи** на экране (например «R» или «LMB») — нажмите новую клавишу, и она
  переназначится. Если эта клавиша уже была на другом элементе, они поменяются местами;
- **перетаскивание** элемента — переместить, **колесо** над ним — размер, **ПКМ** — удалить;
- у выбранного элемента в панели: смена клавиши, размер, чувствительность обзора, захват
  мыши в бою, удаление;
- **«Сохранить»** — записать, **«Отмена»** — вернуть как было.

F1–F12 и левый Alt назначить нельзя: они заняты программой.

### Файлы профилей

Профили лежат в `~/.config/phonecast/profiles/*.json`. Их можно править вручную
и копировать между компьютерами. Координаты задаются долями экрана: `0..1` по ширине и высоте.

```json
{
  "name": "Моя игра",
  "packages": ["com.example.game"],
  "mappings": [
    {"type": "joystick", "x": 0.16, "y": 0.72, "radius": 0.13,
     "up": "w", "left": "a", "down": "s", "right": "d", "walk": "lshift"},
    {"type": "aim", "toggle": "`", "x": 0.68, "y": 0.45, "radius": 0.3, "sensitivity": 1.0},
    {"type": "tap", "key": "mouse_left", "x": 0.86, "y": 0.62},
    {"type": "tap", "key": "space", "x": 0.93, "y": 0.78},
    {"type": "swipe", "key": "e", "from": [0.5, 0.6], "to": [0.5, 0.3], "duration": 150},
    {"type": "android", "key": "escape", "action": "back"}
  ]
}
```

| Тип | Назначение |
|---|---|
| `tap` | касание в точке, пока клавиша зажата |
| `joystick` | виртуальный стик на 4 клавишах, `walk` — клавиша половинного хода |
| `aim` | обзор мышью; `toggle` — клавиша захвата мыши |
| `swipe` | свайп из `from` в `to` за `duration` мс |
| `skill` | атака с прицелом: палец тянется от кнопки в сторону курсора (`origin` — где на экране персонаж, `range` — расстояние курсора для полного отклонения) |
| `android` | системная кнопка: `back`, `home`, `recents`, `menu`, `power`, `volume_up`, `volume_down`, `mute` |

Названия клавиш: `a`…`z`, `0`…`9`, `f1`…`f12` (F1–F12 заняты программой), `space`, `enter`,
`escape`, `tab`, `backspace`, `lshift`, `rshift`, `lctrl`, `rctrl`, `lalt`, `ralt`, `capslock`,
`up`, `down`, `left`, `right`, `` ` ``, `-`, `=`, `[`, `]`, `;`, `'`, `,`, `.`, `/`, `kp0`…`kp9`,
а также кнопки мыши: `mouse_left`, `mouse_right`, `mouse_middle`, `mouse_x1`, `mouse_x2`.

В `profiles/` лежат профили Standoff 2 и Brawl Stars и два примера («Шутер» и «MOBA»).
Они копируются в папку профилей; новые профили из обновлений тоже появятся сами. Ваши
изменения в профилях обновление не перезаписывает, а удалённые вами профили не возвращает.

Для прицела (`aim`) можно указать `"auto": true`: тогда мышь захватывается сразу, как только
включается раскладка (так сделано в профиле Standoff 2).

## Если что-то не работает

- **`No device found`**: проверьте кабель (нужен кабель с передачей данных), включите «Отладку по USB»,
  переподключите кабель. Если `adb devices` показывает `no permissions`, установите udev-правила:
  `sudo apt install android-sdk-platform-tools-common` (Ubuntu) или `android-udev` (Arch),
  затем переподключите телефон.
- **`unauthorized`**: разблокируйте телефон и подтвердите запрос отладки.
- **Картинка есть, касания не работают**: на Xiaomi включите «Отладка по USB (настройки безопасности)».
- **Игра не реагирует на ввод или «видит» его как чит**: некоторые игры блокируют эмулированный ввод.
  Это ограничение самой игры.
- **Нет звука**: звук передаётся только с Android 11+. Также нужен `pacat` (пакет `pulseaudio-utils`)
  или `pw-cat`/`aplay`.
- **Тормозит**: нажмите **F1**, внизу справки видно FPS и отставание картинки. Если отставание
  больше 0,3 с, программа пропускает устаревшие кадры и показывает свежий, так что задержка не
  копится. Если картинка всё равно не успевает, уменьшите в `settings.json` сначала `bit_rate`
  (например `"4M"`), затем `max_size` (например `1024`). Звук передаётся в сжатом виде (Opus),
  поэтому почти не занимает кабель.
- **Запуск из меню ничего не показывает**: лог лежит в `~/.cache/phonecast/phonecast.log`.
- **Подробный лог с телефона**: `./run.sh -v`.

## Разработка

```bash
python3 -m unittest discover -s tests
```

Тесты включают сквозной сценарий: поддельный `adb` и поддельный телефон говорят на настоящем
протоколе scrcpy и отдают настоящий H.264 с поворотом экрана посреди потока. Настоящее
приложение запускается без окна (SDL dummy), и тест проверяет байты, которые оно отправляет
на «телефон»: касания, текст, джойстик, прицел, мультитач и сохранение раскладки в редакторе.

Структура:

- `phonecast/session.py`: запуск scrcpy-server через ADB, сокеты, протокол
- `phonecast/control.py`: кодирование управляющих сообщений (касания, клавиши, текст…)
- `phonecast/media.py`: декодирование видео (PyAV) и воспроизведение звука
- `phonecast/keymap.py`: профили и движок раскладки (клавиши → касания)
- `phonecast/editor.py`: редактор раскладки
- `phonecast/app.py`: окно трансляции, ввод, отрисовка
- `phonecast/hid.py`: виртуальные USB-клавиатура и мышь для ПК-режима
- `phonecast/launcher.py`: окно приложения: ожидание телефона, переподключение
- `phonecast/settings.py`: настройки и автоматическое снижение качества
