# Phonecast

Трансляция экрана Android-телефона на ноутбук с Linux **по USB-кабелю** с полным управлением:
мышь работает как палец, клавиатура печатает текст, а для игр можно **назначить клавиши и мышь
на кнопки на экране**: джойстик на WASD, обзор мышью, стрельба на ЛКМ и так далее.

Приложение на телефон ставить не нужно. Захват экрана, звука и ввод касаний выполняет
[scrcpy-server](https://github.com/Genymobile/scrcpy): это небольшая Java-программа, которая
временно запускается через ADB и исчезает после отключения. Всё, что работает на ноутбуке
(окно, декодирование видео, раскладки, редактор), реализовано здесь, на Python.

- Видео H.264 с аппаратного кодировщика телефона, до 60 FPS, низкая задержка
- Звук с телефона (Android 11+)
- Мультитач: джойстик, прицел и кнопки можно зажимать одновременно
- Редактор раскладки прямо в окне, профили для каждой игры, автопереключение по приложению
- Клавиши определяются по физическому положению, поэтому WASD работает и при русской раскладке

## 1. Подготовка телефона (один раз)

1. **Настройки → О телефоне** → 7 раз нажмите «Номер сборки», чтобы включить режим разработчика.
2. **Настройки → Для разработчиков** → включите **Отладка по USB**.
3. Только для **Xiaomi / Redmi / POCO**: там же включите **«Отладка по USB (настройки безопасности)»**.
   Без этого картинка будет, а касания работать не будут.
4. Подключите телефон кабелем. На телефоне появится запрос «Разрешить отладку по USB?».
   Отметьте «Всегда разрешать» и нажмите «Разрешить».

Кабель должен передавать данные, а не только заряжать.

## 2. Установка на ноутбук

```bash
# Ubuntu / Debian / Mint
sudo apt install adb python3 python3-venv pulseaudio-utils xclip
# Fedora:  sudo dnf install android-tools python3 pulseaudio-utils xclip
# Arch:    sudo pacman -S android-tools python libpulse xclip

git clone <этот репозиторий> && cd Remote
./install.sh
```

`install.sh` создаёт виртуальное окружение `.venv`, ставит зависимости (PyAV, pygame, numpy)
и скачивает `scrcpy-server` с проверкой контрольной суммы.

Проверка: `adb devices` должен показать телефон со статусом `device`.

## 3. Запуск

```bash
./run.sh
```

Полезные параметры (полный список в `./run.sh --help`):

| Параметр | Что делает |
|---|---|
| `-f` | сразу в полноэкранном режиме |
| `-m 1920` | разрешение видео (по большей стороне); `-m 0` — как на телефоне |
| `-b 16M` | битрейт видео: выше — чётче, но больше нагрузка |
| `--max-fps 90` | ограничение FPS (если телефон умеет больше 60) |
| `--screen-off` | выключить экран телефона (трансляция продолжается, батарея экономится) |
| `--no-audio` | без звука |
| `-p "Шутер (пример)"` | запустить с этим профилем раскладки |
| `-s SERIAL` | выбрать телефон, если подключено несколько |

## 4. Управление

| Клавиша | Действие |
|---|---|
| **ЛКМ** | касание / свайп |
| **ПКМ** | «Назад» (если экран выключен, включает его) |
| **СКМ** (колесо) | «Домой» |
| Колесо | прокрутка |
| Клавиатура | ввод текста, включая кириллицу; Enter, Backspace и стрелки работают |
| **Ctrl+V** | вставить на телефон текст из буфера обмена ноутбука |
| **F1** | справка |
| **F2** | вкл/выкл раскладку (игровой режим) |
| **F3** | редактор раскладки |
| **F4** | показать/скрыть подсказки кнопок поверх игры |
| **F5** | следующий профиль |
| **F6** | недавние приложения |
| **F7** | шторка уведомлений |
| **F8 / F9** | громкость − / + |
| **F10** | выключить/включить экран телефона |
| **F11** | полный экран |
| **F12** | повернуть экран |

## 5. Раскладка для игр

### Быстрый способ: через редактор

1. Откройте игру на телефоне.
2. Нажмите **F3**, чтобы открыть редактор. Поверх экрана игры появятся уже назначенные элементы.
3. Нажмите **N**: будет создан новый профиль для этой игры. Он сам включится, когда игра окажется на экране.
4. Назначьте кнопки:
   - **клик по кнопке игры, затем клавиша** (или кнопка мыши): клавиша будет нажимать эту точку.
     Пока клавиша зажата, «палец» остаётся на экране, так что можно зажимать бег, прицел и т. п.;
   - **J** под курсором: джойстик WASD (Shift — шаг, половина отклонения). Размер меняется колесом;
   - **M** под курсором: зона обзора (прицел). В игре клавиша **`** (Ё, под Esc) захватывает
     мышь, и её движение крутит камеру. Размер зоны меняется колесом,
     чувствительность клавишами **[** и **]**;
   - перетаскивание двигает элемент, **ПКМ** или **Delete** его удаляет.
5. Снова нажмите **F3** или **Esc**: профиль сохранится.
6. **F2** включает игровой режим (если профиль привязан к игре, он включится сам).

В игровом режиме с включённым прицелом ЛКМ/ПКМ нажимают назначенные на них кнопки
(например, «Огонь» и «Прицелиться»). С выключенным прицелом ЛКМ работает как обычное касание,
чтобы можно было нажимать меню.

### Файлы профилей

Профили лежат в `~/.config/phonecast/profiles/*.json`. Их можно править вручную
и копировать между компьютерами. Координаты задаются долями экрана: `0..1` по ширине и высоте.

```json
{
  "name": "Моя игра",
  "packages": ["com.example.game"],
  "mappings": [
    {"type": "joystick", "x": 0.16, "y": 0.72, "radius": 0.13,
     "up": "w", "left": "a", "down": "s", "right": "d", "walk": "lshift"},
    {"type": "aim", "toggle": "`", "x": 0.68, "y": 0.45, "radius": 0.3, "sensitivity": 1.0},
    {"type": "tap", "key": "mouse_left", "x": 0.86, "y": 0.62},
    {"type": "tap", "key": "space", "x": 0.93, "y": 0.78},
    {"type": "swipe", "key": "e", "from": [0.5, 0.6], "to": [0.5, 0.3], "duration": 150},
    {"type": "android", "key": "escape", "action": "back"}
  ]
}
```

| Тип | Назначение |
|---|---|
| `tap` | касание в точке, пока клавиша зажата |
| `joystick` | виртуальный стик на 4 клавишах, `walk` — клавиша половинного хода |
| `aim` | обзор мышью; `toggle` — клавиша захвата мыши |
| `swipe` | свайп из `from` в `to` за `duration` мс |
| `android` | системная кнопка: `back`, `home`, `recents`, `menu`, `power`, `volume_up`, `volume_down`, `mute` |

Названия клавиш: `a`…`z`, `0`…`9`, `f1`…`f12` (F1–F12 заняты программой), `space`, `enter`,
`escape`, `tab`, `backspace`, `lshift`, `rshift`, `lctrl`, `rctrl`, `lalt`, `ralt`, `capslock`,
`up`, `down`, `left`, `right`, `` ` ``, `-`, `=`, `[`, `]`, `;`, `'`, `,`, `.`, `/`, `kp0`…`kp9`,
а также кнопки мыши: `mouse_left`, `mouse_right`, `mouse_middle`, `mouse_x1`, `mouse_x2`.

В `profiles/` лежат два примера («Шутер» и «MOBA»). При первом запуске они копируются
в папку профилей. Это заготовки: откройте игру, нажмите F3 и передвиньте элементы на
кнопки своей игры.

## Если что-то не работает

- **`No device found`**: проверьте кабель (нужен кабель с передачей данных), включите «Отладку по USB»,
  переподключите кабель. Если `adb devices` показывает `no permissions`, установите udev-правила:
  `sudo apt install android-sdk-platform-tools-common` (Ubuntu) или `android-udev` (Arch),
  затем переподключите телефон.
- **`unauthorized`**: разблокируйте телефон и подтвердите запрос отладки.
- **Картинка есть, касания не работают**: на Xiaomi включите «Отладка по USB (настройки безопасности)».
- **Игра не реагирует на ввод или «видит» его как чит**: некоторые игры блокируют эмулированный ввод.
  Это ограничение самой игры.
- **Нет звука**: звук передаётся только с Android 11+. Также нужен `pacat` (пакет `pulseaudio-utils`)
  или `pw-cat`/`aplay`.
- **Тормозит**: задержка не должна накапливаться: если компьютер не успевает, программа
  пропускает устаревшие кадры и показывает свежий. Если это происходит часто, внизу окна появится
  подсказка. Тогда уменьшите разрешение и частоту кадров: `./run.sh -m 1024 --max-fps 30`.
- **Подробный лог с телефона**: `./run.sh -v`.

## Разработка

```bash
python3 -m unittest discover -s tests
```

Тесты включают сквозной сценарий: поддельный `adb` и поддельный телефон говорят на настоящем
протоколе scrcpy и отдают настоящий H.264 с поворотом экрана посреди потока. Настоящее
приложение запускается без окна (SDL dummy), и тест проверяет байты, которые оно отправляет
на «телефон»: касания, текст, джойстик, прицел, мультитач и сохранение раскладки в редакторе.

Структура:

- `phonecast/session.py`: запуск scrcpy-server через ADB, сокеты, протокол
- `phonecast/control.py`: кодирование управляющих сообщений (касания, клавиши, текст…)
- `phonecast/media.py`: декодирование видео (PyAV) и воспроизведение звука
- `phonecast/keymap.py`: профили и движок раскладки (клавиши → касания)
- `phonecast/editor.py`: редактор раскладки
- `phonecast/app.py`: окно, ввод, отрисовка
